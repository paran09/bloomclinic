# Bloom — Antenatal Journey Companion

A static, single-page site for GitHub Pages. The Netlify version is unchanged.

## Publish with GitHub Pages

1. Create a public GitHub repository named `mangalam-anc`.
2. Add `index.html` to the repository root and push to the `main` branch.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. GitHub will show the Pages URL after the deployment finishes.

No build step or external assets are required. Pregnancy dates, blood pressure entries, and checklist progress are stored in the visitor's browser using local storage.
