# Bloom — Antenatal Journey Companion

A static, single-page site hosted with GitHub Pages.

- Live site: https://paran09.github.io/bloomclinic/
- Original Netlify site: https://mangalam-anc.netlify.app/ (unchanged)

GitHub Pages publishes the `main` branch from the repository root. No build step or external assets are required. Pregnancy dates, blood pressure entries, and checklist progress are stored locally in each visitor's browser.
